# references

Materi belajar gaya milikmu sendiri.

- `frames/`  38 frame referensi (short01 sampai short20, frame 60 dan 180) untuk dibandingkan dengan still kamu.
- `sheets/`  20 contact sheet, satu per video referensi.
- `reports/` laporan pengukuran terkalibrasi studio (`motion.md`, `depth.md`, `grade.md`, `lighting.md`, `outlines.md`, `characters.md`, `textures.md`, dll.).
- `measure-template.md`  cetakan laporan ukur per topik.

Nama file `shortNN_FFFF.jpg` berarti video referensi ke-NN pada frame FFFF.

## Aturan
Materi ini **hanya untuk belajar** dan bersifat privat. Jangan diunggah atau dipublikasikan, dan jangan
menyalin cerita, tokoh, atau shot-nya. Folder `frames/` dan `sheets/` sengaja ada di `.gitignore`
supaya tidak ikut ter-commit. Lihat `docs/07-originality-policy.md`.

## Cara memakai
Minta `qa-inspector` membandingkan still kamu dengan frame di sini lewat skill `atelier-look-match`.
