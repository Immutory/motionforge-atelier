# assets

Hanya aset dengan lisensi jelas. Catat setiap aset di tabel ini.

| File | Sumber | Lisensi | Catatan |
|------|--------|---------|---------|
| `characters/*` | Prosedural Canvas2D (`engine/cast/` & `productions/charlab/`) | Karya sendiri (MIT) | Katalog sheet, frame, & preview animasi 9 karakter orisinal (termasuk Pemeran Utama #1 Bang Utoh) |
| `sets/*` & `public/sets/*.glb` | Model 3D Blender 5.3 (`assets/sets/blend/bang_utoh_sets.blend`) | Karya sendiri (MIT) | 4 Set Dunia 3D (`KampungSet`, `WarkopSet`, `KostSet`, `KampusSet`) terintegrasi di `engine/sets/` |
| `sets/textures/*` | Dibuat dengan `sets/generate_pbr_textures.py` | Karya sendiri (MIT) | 20 tekstur PBR (pasangan `_diff` dan `_norm`) |

Folder: `characters/` (katalog karakter & sheet), `sets/` (file Blender `.blend`, sheet & frame set 3D), `props/` (model atau data prop), `textures/` (tekstur buatan sendiri), `fonts/` (font berlisensi terbuka).
